CONTRIBUTING

1. Pendahuluan

Dokumen ini menjelaskan bentuk kontribusi anggota Kelompok 3 dalam pengembangan dan pengujian aplikasi Sistem Pendukung Keputusan Pemilihan Guru Berprestasi Menggunakan Metode Simple Additive Weighting (SAW).

Setiap anggota kelompok berkontribusi dalam proses pengembangan, penyusunan dokumentasi, pengujian sistem, serta evaluasi hasil pengujian agar aplikasi dapat berjalan sesuai dengan kebutuhan yang telah ditentukan.

4. Bentuk Kontribusi

Kontribusi dalam proyek ini meliputi:

Pengembangan dan pemeliharaan aplikasi.

Identifikasi kebutuhan sistem.

Penyusunan skenario dan test case.

Pelaksanaan pengujian menggunakan metode Black Box Testing.

Pemeriksaan kesesuaian Expected Result dan Actual Result.

Dokumentasi hasil pengujian dan bukti pengujian.

Evaluasi serta perbaikan terhadap kesalahan yang ditemukan.

Penyusunan dan pemeliharaan dokumentasi proyek pada GitHub.

5. Alur Kontribusi pada GitHub

Kontribusi proyek dilakukan melalui repositori GitHub dengan tahapan berikut:

Anggota kelompok mengakses repositori proyek.

Anggota melakukan perubahan atau penambahan file sesuai tanggung jawab masing-masing.

Perubahan disimpan dan diunggah ke repositori melalui commit.

Setiap perubahan diperiksa agar sesuai dengan kebutuhan proyek.

Perubahan digabungkan ke repositori utama setelah diperiksa dan disetujui oleh kelompok.

Dokumentasi proyek diperbarui apabila terdapat perubahan aplikasi atau hasil pengujian.

6. Ketentuan Kontribusi

Setiap anggota bertanggung jawab terhadap tugas yang telah disepakati.

Setiap perubahan harus berkaitan dengan pengembangan atau dokumentasi proyek.

Anggota harus menjaga konsistensi struktur dan isi dokumentasi.

Hasil pengujian harus dicatat berdasarkan kondisi aktual aplikasi.

Setiap perubahan pada repositori harus dapat ditelusuri melalui riwayat commit GitHub.

7. Penutup

Dokumen CONTRIBUTING ini dibuat sebagai pedoman pembagian tanggung jawab dan pelaksanaan kontribusi anggota Kelompok 3 dalam pengembangan serta pengujian aplikasi Sistem Pendukung Keputusan Pemilihan Guru Berprestasi Menggunakan Metode SAW.
